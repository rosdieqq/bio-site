# rosdieqq Bio Page

Open `index.html` directly in a browser. No backend, build tools, or install step are required.

## Replace Assets

- Background GIF: put your file at `assets/bg.gif`
- Optional video background: put your file at `assets/bg.mp4`
- Music: put your file at `assets/music.mp3`
- Avatar: replace `assets/avatar.svg` or update `SETTINGS.avatar` in `script.js`

## Edit Links

Open `script.js` and change:

- `discordUrl`
- `steamUrl`

## Languages

All visible UI text lives in the `I18N` object in `script.js` with English, Russian, and Ukrainian versions.
